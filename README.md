# GeoPoint

**Michel Balzan da Veiga**
**RA:** 1139750
**Professor:** Luciano Rodrigo Ferretto 
**Universidade Atitus**

API REST desenvolvida em Java com Spring Boot para gerenciamento de pontos turísticos, permitindo cadastrar, listar, consultar, editar e excluir registros, com validação de dados e controle de nomes duplicados.

## Como executar

Configure o banco de dados PostgreSQL, informe a senha no arquivo local `config/application.properties` e execute a classe `GeoPointApplication`.

A API estará disponível em `http://localhost:8080/api/points`.
